# Homepage media assets

These local thumbnails support the homepage coverflow; `_pages/media.md` remains the source of truth for all coverage and source article URLs. Publisher images and marks identify their original outlets, not endorsements beyond the linked coverage.

- `ut-austin.webp`: photograph from the UT Graduate Studies LinkedIn post's `og:image`.
- `forbes.webp`: image published with the linked Forbes article, obtained from its AMP page metadata. The regular page restricts browser screenshots; this is the article image, not a reconstructed screenshot.
- `peoples-daily.webp`, `tsinghua.webp`, `science-daily.webp`, `synced-matraix.webp`, `synced-asi-bench.webp`: cropped browser screenshots of their linked articles, captured September 6, 2026. Tsinghua's working capture URL uses `www.tsinghua.edu.cn`.
- `south-jetty.webp`: the coastal-water-quality illustration published with the South Jetty article (credited there to Zong-Liang Yang).
- `mango-tv.webp`: the linked episode's YouTube thumbnail.
- `logos/`: outlet marks from the linked publisher pages, LinkedIn organization image, or the episode thumbnail. The Synced logo is the same outlet asset used in Amber's reference commit.

Card CSS and JavaScript are adapted from [AmberLJC's reference commit](https://github.com/AmberLJC/AmberLJC.github.io/commit/6e229f2fb045ba154b46190b62b018b383e50ec4), with local theme, accessibility, and responsive sizing adjustments.
