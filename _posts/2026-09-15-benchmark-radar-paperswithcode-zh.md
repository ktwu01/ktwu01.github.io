[Papers with Code](https://paperswithcode.co/paper/2609.11115) 收录了我们的论文 *Benchmark Radar: A Living Database and Search Engine for AI Benchmarks and Evaluation*（arXiv:2609.11115），附 TL;DR、摘要、代码仓库与项目页。

> 作者：[Koutian Wu](https://www.linkedin.com/in/ktwu01/)；[GitHub: ktwu01](https://github.com/ktwu01/)

这条收录携带论文 TL;DR（可搜索的活体数据库与 AI 评测基准发现引擎）、完整摘要、retrieval 任务标签与大语言模型方法标签。

页面链接了[代码仓库](https://github.com/ktwu01/benchmark-radar)、[benchmark-radar.org](https://benchmark-radar.org/) 项目页，以及 arXiv 摘要页与 PDF。从 Papers with Code 进来的读者，一键从论文走到可运行的系统。

Papers with Code 是 ML 研究者确认论文是否附带代码数据的地方。在这里被收录，Benchmark Radar 就站上了读者从阅读走向复现的必经之路。

查看 [Papers with Code 收录页](https://paperswithcode.co/paper/2609.11115)，或在我的[媒体报道页](/media/#benchmark-radar-paperswithcode)浏览全部 Benchmark Radar 报道。
