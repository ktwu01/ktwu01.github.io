[CatalyzeX](https://www.catalyzex.com/author/Koutian%20Wu) now has an author page for me. CatalyzeX pairs machine learning papers with the code that goes with them, so a reader who finds a paper can jump straight to a working version instead of rebuilding it from the PDF.

> Author: [Koutian Wu](https://www.linkedin.com/in/ktwu01/); [GitHub: ktwu01](https://github.com/ktwu01/)

That matches how I like to publish. [Benchmark Radar](https://benchmark-radar.org/) ships with its [code on GitHub](https://github.com/ktwu01/benchmark-radar), and the arXiv page for [the paper](https://arxiv.org/abs/2609.11115) already offers CatalyzeX's code finder as one of its code links. The author page gathers my papers in one place for anyone who wants code first.

See my [CatalyzeX author page](https://www.catalyzex.com/author/Koutian%20Wu), or find my other researcher profiles on my [Media Coverage](/media/#profiles) page.
