The run fetched 1,256 items, kept 540, and recommended 171.

repo2bench converts Python repositories into coding-agent tasks mined from version history or created by removing functions. It admits a model-drafted task only after deterministic checks, including abstract syntax tree mutation testing, which alters code systematically to verify that the tests detect faults.

Era by Eon extends an enterprise-agent test after four leading models scored 22 to 25 of its original 27 questions. The added templates require agents to infer hidden facts from conflicting or indirect company records. Code generates each company and computes the exact answers without a language model.

The LongHorizon Orchestrator Benchmark isolates the decisions made by a robot's vision-language orchestrator while keeping the low-level control policy fixed. It separately exercises instruction decomposition, visual completion checks, and memory of finished goals during multi-object manipulation.

Why this matters.

When the answer key comes from code and not from another model, a score can be rechecked by anyone.
