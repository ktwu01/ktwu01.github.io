## "薅 tokens"是什么意思

中文网络俚语 薅（hāo）意为"揪"或"收割"，好比从羊身上薅羊毛。薅 tokens 是一个颇具感情色彩的说法，指在各大提供商、学生计划、黑客松券和提供商促销之间，合法地收集免费的 API 额度。这里没有任何黑客手段或漏洞利用。它只是一份已经存在、并且乐于给开发者发放免费 token 的计划清单。

## 为什么会有这个仓库

当我开始上线 AI 副业项目时，我注意到了三件事：

1. 免费额度散落在几十个提供商的博客上，从来没有一个地方集中收录过。
2. 学生和学术计划往往发放慷慨的额度，但没人告诉你它们的存在。
3. 地区特定的提供商（尤其是中国的）有着截然不同的定价曲线。

于是我开始做笔记。仓库就是这样成长起来的。

## 你会在这里找到什么

- **OpenAI、Anthropic Claude、Google Gemini 等提供商的免费层**。
- **凭 `.edu` 邮箱就能获得 API 额度的学生和学术计划**。
- **常在活动之后无人领取的黑客松优惠券**。
- **打包了 LLM API 访问的云提供商额度**（Azure、AWS、GCP）。
- **定价结构不同的区域提供商**（中国、欧盟等）。

## 这些内容适合谁

- 在预算紧张的情况下上线 AI 产品的独立黑客。
- 正在学习用 LLM API 构建东西的学生。
- 在没有机构计费账户的情况下跑实验的研究者。
- 任何看腻了 "monthly quota exceeded"（月度配额已超）字样的人。
