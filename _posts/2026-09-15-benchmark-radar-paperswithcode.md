[Papers with Code](https://paperswithcode.co/paper/2609.11115) listed our paper *Benchmark Radar: A Living Database and Search Engine for AI Benchmarks and Evaluation* (arXiv:2609.11115), with its TL;DR, abstract, code repository, and project page.

> Author: [Koutian Wu](https://www.linkedin.com/in/ktwu01/); [GitHub: ktwu01](https://github.com/ktwu01/)

The listing carries the paper's TL;DR — a searchable living database and discovery engine for AI evaluation benchmarks — alongside the full abstract, the retrieval task tag, and the large-language-model method tag.

It links the [code repository](https://github.com/ktwu01/benchmark-radar), the project page at [benchmark-radar.org](https://benchmark-radar.org/), and both the arXiv abstract page and PDF. Readers arriving from Papers with Code can move from the paper to the running system in one click.

Papers with Code is where ML researchers check whether a paper ships code and data. A listing there puts Benchmark Radar on the path researchers already walk from reading to reproducing.
