过时运行不再能污染快照数据，微信群正式公开。第二十二天强化了数据完整性并扩展了社区渠道。

> 作者：[Koutian Wu](https://www.linkedin.com/in/ktwu01/)；[GitHub: ktwu01](https://github.com/ktwu01/)

**Benchmark Radar 已上线。** 每天追踪新的 AI 基准测试、数据集与排行榜：[打开仪表盘](https://benchmark-radar.org/) 或 [在 GitHub 上 Star](https://github.com/ktwu01/benchmark-radar)。

你好，我是 Koutian。第二十二天，我们守住了数据的底线。

先说「过时运行保护」。每天雷达会存一份当天的数据快照。但有时任务触发晚了，跑出来的是旧数据。我们改了：这种过时运行不能再覆盖掉更新的快照。这是 PR #235，我们把它标成了 P1，也就是数据完整性里最该先修的问题。你看到的快照，永远是那一拨里最新的，不会被旧数据反咬一口。

GitHub Pages 的发布流程也改了。以前只有改了源代码才重新发布，现在包文件（依赖库）一变也会触发。这样部署永远跟着依赖走，不会脱节。你打开网站，看到的版本和代码是同步的。

中英文 README 里都放了微信群二维码。微信是中国 AI 从业者主要的聊天渠道，群容易进了，参与门槛就低了。你想加入社区，扫一下就行。

社区频道的节奏我们记下来了，频道列表也更新了。你订阅时能看清哪些是每天发、哪些是每月发。

有个老问题修了（issue #98）：注册表里几个基准测试的链接和日期写错了，我们更正了。你点进去不会再跑到死链。

我们加了主流大模型厂商的 RSS 订阅源（RSS，一种让你订阅更新的信息流）。同时加了一组记分卡对照，把「模型发了」和「它在基准测试上的成绩」连起来。你以前只知道有哪些测试，现在还能顺藤摸瓜看到模型考得咋样。

中文翻译的验证加固了。针对复查发现的问题，我们对中文翻译文件跑了 ruff 格式检查。中文 README 也改得更清楚，更新到了项目当下的状态。

每天由 GPT 生成的文字，在中文模式下现在真的是中文了（issue #231）。你切到中文，读到的总结不再是中英混着。

探索视图也简化了（#242），少了一些花里胡哨的东西。你翻看时眼睛清爽些。

为什么值得你关心。

过时运行保护是当天最关键的一修。一个用旧数据盖掉新数据的雷达，比没有雷达还糟，因为它骗你信任。P1 这个标记说明它多严重：对数据工具来说，数据错了就是没法活。你拿着的数据，现在是真的。

微信群二维码是社区的一步。微信是中国 AI 人主要的沟通地，群好加了，你就更容易融进来。你有什么问题，群里能直接问。

主流大模型的 RSS 订阅源，把雷达的活儿从「有哪些测试」扩到了「模型在这些测试上表现如何」。这是一步大跨：雷达同时盯着评测工具和评测结果了。你一个页面，能看完整个链条。

解决的问题。

- #232: 基准测试 URL/日期修正与 RSS 订阅源
- #235: P1 数据完整性（过时运行保护）
- 微信群二维码
- 社区频道节奏
