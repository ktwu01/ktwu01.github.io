过时运行不再能污染快照数据，微信群正式公开。第二十二天强化了数据完整性并扩展了社区渠道。

> Author: [Koutian Wu](https://www.linkedin.com/in/ktwu01/); [GitHub: ktwu01](https://github.com/ktwu01/)

## 今日交付

**过时运行保护。** 每日快照持久化现已防止过时运行的覆盖。如果某次运行产生了过时数据（例如因触发延迟），它不会覆盖更新的快照。此为 PR #235，标记为 P1 数据完整性问题。

**Pages 触发器扩展至包变更。** GitHub Pages 工作流现在在包文件变更时也会触发，而非仅在源代码变更时。这确保部署与依赖更新保持同步。

**微信群二维码。** 中英文 README 中均添加了微信群二维码。

**社区频道节奏更新。** 记录了月度社区频道节奏，更新了频道列表。

**基准测试 URL 与日期修正。** 修复了 issue #98：在注册表中更正了基准测试 URL 和日期。

**主流 LLM RSS 订阅源。** 添加了主流 LLM 提供商的 RSS 订阅源，以及将模型发布与其基准测试结果关联的记分卡对。

**中文验证加固。** 针对审查发现，加固了中文翻译验证。对中文翻译文件应用了 ruff 格式化。

**中文 README 修订。** 修订了中文 README 的清晰度，并更新至当前项目状态。

**GPT 生成文本中文化。** 每日 GPT 生成的文本现已在中文模式下以中文呈现（issue #231）。

**探索视图简化。** 简化了探索视图（#242），减少视觉杂乱。

## 为什么重要

过时运行保护是当天最关键的修复。一个用过时数据覆盖新鲜数据的雷达，不如没有雷达，因为它侵蚀用户信任。P1 标记反映了严重程度：对数据产品而言，数据完整性问题就是生存问题。

微信群二维码是一次社区建设举措。微信是中国 AI 从业者的主要沟通渠道。让群组易于加入，降低了社区参与的门槛。

主流 LLM 提供商的 RSS 订阅源将雷达的覆盖范围从「存在哪些基准测试」扩展到「模型在这些基准测试上的表现如何」。这是一次质的飞跃：雷达现在同时追踪评估工具和评估结果。
