Benchmark Radar 的第三十天。写到今天，这份日志正式变成一场公开直播：一个开源项目如何从零走向 1000 颗星。先报分数：今天记分牌上写着 86。

> 作者：[Koutian Wu](https://www.linkedin.com/in/ktwu01/)；[GitHub: ktwu01](https://github.com/ktwu01/)

先解释几个词：星标是 GitHub 用户留在仓库上的书签，星标数是衡量一个项目受关注度最粗糙的指标；fork 是别人复制一份你的仓库、由他自己持有；徽章是 README 顶部那些带字的小图片；注册表是雷达维护的基准总表。

先把记分牌摆出来。仓库 7 月 27 日公开。头四个星期每天更新，一共攒了 33 颗星，大约一天一颗。然后 8 月 24 日一天进来 27 颗，今天又进来 26 颗，两天 53 颗，总计 86 颗，外加 17 个 fork。这个系列现在公开追的目标是 1000 颗，还差 914。

8 月 24 日当天没有发布任何大功能。往前三天落地的是管道工程：带引用元数据的 v0.8.0、BibTeX 引用块和 Cite 按钮、生成的 sitemap 和规范链接让搜索引擎读得懂每个视图、砍掉首屏加载时间的精简首包、挪到右上角的 README 语言切换，以及全站的白话改写。我没法证明其中哪一项搬动了数字。能说的是：跳变发生在项目变得好引用、好找到、打开快之后；而在此之前的四个星期，它一样都不占。

PR #352 把记分牌本身做进了仓库。仓库自带的一段脚本会从 GitHub 的 GraphQL API 拉取星标历史，渲染出浅色和深色两版 SVG 图表放进两份 README。每次合并、每来一颗新星都会重新生成，另有每日兜底运行，产物发布到 `star-history` 分支，README 预览不用等定时任务。第一张图定格在 57 颗星。从今天起，这份日志记录的每一天在图上都有一条线，任何人都能核对。

PR #358 带来了第一份来自项目外部的注册表贡献。junjiezhou1122 在 #347 下补进四个基准：JointAVBench（多模态，2025 年 12 月 14 日发布，ICLR 2026）、OmniVideoBench（多模态，2025 年 10 月 12 日，NJU-LINK）、ASI-Bench（智能体方向，2026 年 8 月 18 日）和 SWE-bench Science（编程智能体，2026 年 8 月 20 日，OpenMOSS/Fudan）。每个字段都取自 arXiv 摘要页或官方仓库，不靠记忆，每条按 CONTRIBUTING.md 的要求带上 caveat。合并前的审查修正了这批条目的会议名、来源链接、领域和披露说明。

PR #364 关掉了 #324，愿望清单上最后一个大数据源。Artificial Analysis 快照原本是个 zip 压缩包，这次解包进仓库目录，重排成注册表的 CSV 格式。共享的归一化辅助函数改为公开，一个归一化器服务所有外部源、按源传参，不再每个源复制一份。分数按记录自己的源归档，新数据源没法再改名模型或混用指标刻度。站点侧，指标选择器退场，分数图的点不再给第三方引用画虚线圈；引用的名字写在点的标签和它的固定卡片里。

PR #370 把 donor 一词从仪表盘文案里清掉。解释身份继承的那句话现在说信息来自匹配到的源卡片，中英文同时修改，因为 donor 是项目内部黑话，读者没义务认识。PR #368 把 issue 模板做成双语，两种语言要求同样的四件事：发生了什么、在哪里、预期行为是什么、为什么重要，另附哪些使用案例值得展示的指引。

PR #366 把展示规则写进在这个仓库干活的智能体会读的 AGENTS.md 和 CLAUDE.md，并把文档里的 CI 流程同步成实际运行的五步。PR #367 精简五徽章页眉，X、LinkedIn、Google Scholar 徽章只留图标和用途，不带用户名，中文 README 同步修改。

为什么要在意

四个星期每天发货，换来一天一星。变得好引用、好找到、打开快之后的两天，来了 53 颗。从这里到 1000，这份日志会继续验证这个观察。没人引用一个找不到的项目，也没人给十秒钟还看不到数字的项目点星。

贡献轨道要在第一位贡献者出现之前铺好。字段必须可溯源、必带 caveat，第一条外部 PR 一次审查就能合并，不用推倒重来；双语模板意味着下一位可以用中文或英文提单。

度量让直播诚实。仓库用自己的脚本画自己的星标曲线，这个系列关于增长的每一句判断，都能对一张所有人可见的图核验。

解决的问题

- #324：Artificial Analysis 快照归一化进目录
- #347：第一位外部贡献者带来 JointAVBench、OmniVideoBench、ASI-Bench、SWE-bench Science
- #351：仓库自己生成并发布星标历史图
- #353：两份 README 的徽章标签精简
- #356：双语 issue 模板
- #340：仪表盘文案清除 donor 黑话
- 记分牌：86 / 1000 星，其中 53 颗来自最近两天
